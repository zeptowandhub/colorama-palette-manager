## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Palette Library** | Organize saved Colorama palettes with tags and project links |
| **Brand Colors** | Store and reference brand color sets with HEX and RGB values |
| **Export Manager** | Export palette data in CSS, ASE, and other format outputs |
| **Color Search** | Search your palette library by hue range or color name |
